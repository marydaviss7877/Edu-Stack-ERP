# EduStack redesign v1

This implementation adapts the useful ideas from the reviewed Stitch output without overwriting the current-design reference.

Open `index.html` directly or serve this directory locally. The redesign is self-contained: `base.css` and `base.js` are local copies of the shared mockup foundations, so the page does not depend on executable assets from another folder. Use the “Current UI” control in the header for before/after comparison.

## Adopted

- Deep indigo academic identity
- Hanken Grotesk display typography with Inter UI text
- Action-first dashboards
- Teacher agenda timeline
- Student fee alert and next-class priority
- Bento-style KPI and exception groupings
- Richer results and financial summaries

## Corrected

- Uses Noto Nastaliq Urdu rather than Noto Serif
- Preserves role-specific mobile navigation
- Separates semantic colors from decorative brand gold
- Keeps tenant branding constrained to safe component roles
- Removes premature “Continue Securely” from QR scanning
- Replaces university-oriented content with Pakistani school content
- Enforces 44px touch targets and reduced-motion support
